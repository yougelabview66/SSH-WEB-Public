# SSH-WEB

轻量级 Web SSH 终端，适合部署在 NAS 的 Docker 中。设计参考了
[huashengdun/webssh](https://github.com/huashengdun/webssh)、
[billchurch/webssh2](https://github.com/billchurch/webssh2)、
[nirui/sshwifty](https://github.com/nirui/sshwifty)。

```
浏览器 (xterm.js) ──WebSocket──> SSH-WEB (Node.js + ssh2) ──SSH──────────────> 目标主机
                                                          └─WSS (Cloudflare)──> cloudflared ──> NAS:22
```

## 功能

- **多设备同时打开同一个标签：最先用的锁定，其他锁住**。最先用的客户端（新建这个会话的那台）锁定这个标签；别的设备打开、切到这个标签都锁着：镜像显示（终端按在用那台的行列排、整体缩放，看到的和它一模一样，不会折乱），终端中间一个弹窗「正在 手机 / 电脑 / 平板 上使用 · 在本机继续」，打字、按键、发送都不发出去（下方输入框里的字留着，接管后回车再发）。只有点弹窗里的「在本机继续」才接管。在用的设备到后台、锁屏断线、关掉页面都不自动换（弹窗改成「手机已断开」）；它自己断线重连、刷新、关掉再打开（同一个浏览器）回来还是它在用。锁住的一端尺寸不改排版，不会来回换、Claude Code 不用反复整屏重打
- **后台会话**：SSH 连接保持在服务器上，关闭浏览器 / 断网后再打开，标签、画面和历史输出全部恢复；手机电脑可同时查看同一会话
- 侧边栏主机可拖动排序（电脑按住拖，手机长按后拖；只在同一分组内，顺序保存在服务器）
- 多标签终端（xterm.js），自适应窗口大小、支持中文、链接可点击、手机可用
- **版本校验**：服务器更新后，还开着的旧网页会在顶部提醒「服务器已更新到 vX（这个页面还是 vY）」，侧边栏底部的版本号变红；点「刷新页面」或红色版本号刷新（和「清缓存刷新」一样，先绕过缓存重新下载网页文件、清掉缓存再刷新），点 × 这个版本不再提醒（页面和服务器的事件连接一连上，服务器就告诉页面自己的版本，服务器重启后页面自动重连时就能发现）；版本号右边有「清缓存刷新」：网页和它用到的文件都绕过浏览器缓存重新下载一遍，清掉 Cache Storage、让 Service Worker 检查更新再刷新（不注销 Service Worker，推送订阅保留），更新后手机上还是旧样子时点它，不用去浏览器设置里清缓存
- **标签多到放不下**：不显示滚动条（电脑上的滚动条会把标签压矮），还有更多标签的那一边渐隐；电脑上两边有 ‹ › 箭头、鼠标在标签栏上滚轮上下滚就能左右翻，手机上手指滑；右边「▾」列出全部标签和状态，点一下切过去；切换标签时当前标签自动完整露出来
- 密码 / 私钥（含私钥密码）/ keyboard-interactive 认证
- **二次验证 (TOTP)**：服务器要求验证码时网页弹窗输入，密码仍自动填写
- **主机指纹校验**：类似 OpenSSH known_hosts，首次连接确认指纹，指纹变化时红色警告
- **性能监控**（参考 FinalShell）：CPU、内存、交换、网速曲线、磁盘 IO、分区用量、进程排行。在顶栏最右边「⋯ 更多」里打开（不常用的按钮收在这个菜单里，顶栏不变宽、标签栏留得宽；监控开着时「⋯」高亮）
- **完成通知**：Claude Code 完成 / 需要确认、长命令结束等终端提示音推送到手机（Web Push）；后台标签响铃时标签名后面显示 🔔（还没看），切过去看了、点开通知跳到那个标签、或者事情已经处理掉了（Agent 接着干活了、在别的设备上看过 / 回答过）就消失
- **Agent 钩子通知**（参考 Orca 的做法）：在顶栏「⋯ 更多 → 🔔 钩子通知」里给当前标签的主机点「安装」（先确认），会往这台主机的 `~/.claude/settings.json` 加上 SSH-WEB 的钩子（原来的设置和你自己的钩子都保留，第一次安装前备份为 `settings.json.bak-sshweb`），并写入 `~/.ssh-web/hook.sh`。之后新开的 Claude Code 开始干活、要权限、问问题、做完、出错时，钩子把事件追加到这台主机的 `~/.cache/ssh-web/hook.log`（只用 sh / grep / sed，什么都不输出、不影响 Claude Code），SSH-WEB 借连着的 SSH 连接实时读（每台主机一个通道）：主机状态以钩子为准，比看屏幕准（tmux 里别的窗口里的 Claude Code 也算）；推送写出具体内容，如「要执行命令：npm test」「要修改：src/a.js」「问你：用哪个数据库？」「做完了：（回复的第一行）」、出错原因；要权限时安卓手机的通知上带「允许 / 拒绝」，点了直接回应（先核对还是那一次、确认框还在才发按键：允许 = 回车选中「1. Yes」，拒绝 = Esc；在 tmux 里直接发给 Claude Code 所在的 pane；结果另弹一条「已允许 / 已拒绝」），iPhone 的网页通知不支持按钮，只能点开处理。状态卡片上还写着 Agent 在做什么：电脑「🖥️ 状态」悬浮窗（和置顶到桌面的小窗口）每张卡片下面一行小字，手机上从「⋯ 更多 → 🖥️ 状态卡片」打开同样的状态卡片（卡片竖着一张一行，展开时固定 250px 宽、贴在右边，收起成小圆点时按内容宽；默认关着，会盖住一部分终端；可以拖动、点卡片切换标签）；电脑上有主机要显示在做什么时也一样，卡片竖着一张一行，悬浮窗展开时固定 375px 宽（收起时照旧按内容宽），不随着那行字变宽（太长的省略，鼠标移上去看全文），鼠标移到标签上也看得到（「▾」标签列表只列主机名和状态），如「在做：（你让它做的事）」「要执行命令：npm test」「问你：……」「做完了：（回复的第一行）」、出错原因（SSH-WEB 更新后钩子脚本多取了字段时，面板里提示「钩子脚本有更新，点重新安装」）。没装钩子的主机照旧看屏幕判断。装了钩子的主机（连上时检查到 `~/.ssh-web/hook.sh`，或在面板里刚装上；某个标签收到过钩子事件也算）只按钩子推送：终端响铃（Claude Code 做完 / 要权限时自己也会响铃）和看屏幕判断出的状态都不再推送（只在页面上显示），同一件事不会推两次；卸载后马上恢复。「卸载」只删 SSH-WEB 加的条目和 hook.sh。同一个标签同一种状态 10 秒内只推一次，换了状态照推。**别的 Agent**：面板里每个 Agent 一行（主机上找到的排前面），各自安装 / 卸载，共用同一个 `hook.sh`（第一个参数是哪个 Agent）：Grok 写进自己的 `~/.grok/hooks/sshweb-status.json`（过滤掉每次用工具前的「tool permission requested」提醒，你说的话去掉 `<user_query>` 包装）；Codex 合并进 `~/.codex/hooks.json`（顶层有 hooks / description 以外的内容就不改，装好后要在 Codex 里输入 `/hooks` 批准一次）；Gemini CLI 合并进 `~/.gemini/settings.json`（脚本先回 `{}`，超时按毫秒写）；Antigravity 在 `~/.gemini/config/hooks.json` 里加一个 `sshweb-status` 分组（用工具前回 `{"decision":"ask"}`，照你自己的权限设置问你，不会自动允许；步骤之间的 Stop 不算做完）；OpenCode 装一个插件 `~/.config/opencode/plugins/sshweb-status.js`。各家的事件换成同一套状态（开始干活 / 用工具 / 要权限 / 问问题 / 做完 / 被打断 / 出错），推送和状态卡片前面写上是谁（如「Codex · 要执行命令：npm test」），子 Agent 的事件不算；通知上的「允许 / 拒绝」只给 Claude Code。卸载一个 Agent 只删它的条目，都没装了才删 `hook.sh`。这些都是照着 Orca 的代码写的，Grok 已实测（状态、推送都对），Codex / Gemini CLI / Antigravity / OpenCode 还没在真的 Agent 上测过，面板里标「未实测」
- **右边栏：项目 + 改动**（参考 Orca / VS Code）：「⋯ 更多 → 🗂️ 项目文件 / 📝 代码改动」打开右边栏，两个选项卡用线条图标（项目 = 两张叠着的文件，改动 = git 分支），共用一个项目目录（顶部那栏：空着 = 自动找钩子报来的 Agent 工作目录 → tmux / psmux 窗格当前目录 → 这个标签里程序的当前目录（Linux 读 /proc）；也能手动填；是 git 仓库就用仓库根目录；钩子脚本更新后要点一次「重新安装」）。**项目**：文件夹树（点开文件夹才读那一层，隐藏 .git，node_modules 之类变灰；改过的文件按 git 状态上色带 M / U / R 标记，里面有改动的文件夹带圆点），点文件直接预览，「⋯」里发路径给 Agent / 复制路径 / 下载 / 看改动；顶部搜索框 = 快速打开：按文件名模糊搜索（git 仓库用 git ls-files，跳过 .gitignore；不是仓库用 find / SFTP 逐层列，最多 5 万个，服务端记 2 分钟），匹配的字母高亮，↑↓ 选、回车预览、Esc 清空，最近打开的排前面；电脑上 Ctrl+Shift+P 直接跳到这个搜索框（Ctrl+P 留给终端）。**改动**：改了哪些文件（修改 / 新增 / 删除 / 改名 / 未跟踪的新文件，带增删行数，选项卡上显示改动数），点开看红绿对比（带行号，删掉的行显示旧行号）；点某一行写批注（电脑上按住 Shift 再点一行 = 选一段，Ctrl+Enter 添加），点「发给 Agent」整理成「请按下面的批注修改代码（路径相对 仓库）：1. a.txt 第 2 行（代码）：批注……」填进输入框，不发送；只读，不暂存、不提交、不撤销。电脑上展开时固定在右边、终端变窄，左边缘拖动调宽度（记住；拖的过程中终端不跟着重排，松手再排一次，不卡），最右边的「»」收起成右边缘一列图标（改动带数字，点哪个展开到哪个），刷新页面保持状态；手机上全屏，右上角「×」关闭，发给 Agent / 发路径后自动关掉。「项目」的样式同 Orca：12px 小字紧凑排列，文件夹是旋转的箭头加文件夹图标，文件按类型显示图标（代码 / 文本 / 图片 / JSON），文件名用 git 状态色（浅色 / 深色主题各一套），被忽略的目录灰色斜体，右键也能打开「⋯」菜单。Agent 做完时右边栏开着就自动刷新。Windows 主机也能用（git 命令连成一次执行，目录用 SFTP 读）
- **会话历史**（参考 Orca）：「⋯ 更多 → 💬 会话历史」（「🕘 历史」面板里的「💬 会话历史」选项卡也一样）列出当前标签所在主机上 Claude Code / Grok / Codex / Gemini CLI / OpenCode 以前的会话，最近的在前，每条有标题（Claude 优先用 /rename 起的名字，再是自动标题）、你说的第一句话、原来的目录、时间和大小；只有 `/clear` 之类命令、没说过话的 Claude 会话不列。打字筛选列出来的，回车或点「搜索」在全部会话内容里搜（不分大小写）。「继续」确认后在当前终端执行恢复命令，如 `cd '原来的目录' && claude --resume <id>`（Grok `grok --resume`、Codex `codex resume`、Gemini `gemini --resume`、OpenCode `opencode --session`），标签里有程序在跑时会提醒先退出；「复制」复制这条命令。会话文件可能很大，在目标主机上用 sh / grep 只抽出要显示的字段，不把文件传回来；Windows 主机（SSH 默认 cmd / PowerShell，没有 sh）改用 SFTP 读，每个文件只读开头和结尾一段，全文搜索分块读、最多搜 15 秒（超时提示只搜了一部分），恢复命令按终端里的 shell 写（先看终端屏幕上的提示符：`PS D:\…>` 是 PowerShell、`D:\…>` 是 cmd；cmd：`cd /d "D:\目录" && claude --resume <id>`，PowerShell：`cd 'D:\目录'; claude --resume <id>`），8 个文件同时读、读过的文件没变就不再读；最多列最近 80 个。再打开会话历史时先显示上次读到的列表，后台刷新。上次选的 Agent 会记住。Claude Code 和 Grok 的格式按实际文件写，Codex / Gemini / OpenCode 照着 Orca 的代码写、标「未实测」（新版 OpenCode 存在 SQLite 里的读不到）
- **收藏命令** 与 **浅色 / 深色主题**（可跟随系统）
- **历史命令**：自动记录执行过的命令，一键执行 / 填入 / 删除，手机和电脑共享
- **延迟显示**：标签栏右侧像苹果双卡一样上下两排信号（上排网页、下排 SSH，每排 4 格，按延迟亮格数和变色，取最近 3 次测量的中间值），点一下显示「网页 N ms · SSH N ms」——网页 = 浏览器 ↔ SSH-WEB（经过 Cloudflare 隧道 / 你的网络），SSH = SSH-WEB ↔ 目标主机；打字、方向键、tmux 滚动都要等一个来回，看这两个数字就知道慢在哪一段（绿 < 80ms，黄 < 200ms，红更慢）
- **主机状态悬浮窗（状态卡片）**：「⋯ 更多 → 🖥️ 状态卡片」开 / 关（电脑默认开，手机默认关；顶栏上不再单独放「🖥️ 状态」按钮；标题栏「–」右边的「×」也能关掉；收起后「–」变成「+」，点了展开）（和输入框模式无关），终端右上角显示主机状态悬浮窗，按住标题栏拖动、「–」收起成小圆点，位置每台电脑各自记住；📌 置顶到桌面（Chrome / Edge 116+ 的文档画中画），浏览器最小化、切到别的软件时也浮在最上面；打开「自动」后，每次打开网页第一次点击或按键时自动钉住（浏览器规定置顶窗口只能由点击 / 按键打开）。小窗口里用「↩ 网页」或点卡片切回网页，小窗口继续留着
- **打字预测回显**（类似 mosh）：网络慢时（网页 + SSH 往返超过 60ms），在终端里直接打的字先在本地显示（带下划线），服务器回显一致就换成真实的字，不一致马上撤掉。每行第一个字先确认程序会回显、并找到真正的输入位置（Claude Code 这类自己画光标的程序靠对比屏幕），所以输密码时不会显示；只在行尾打字时预测，方向键 / 回车会清掉预测，猜错暂停 5 秒。侧边栏「打字预测」可选 自动 / 开 / 关
- **tmux 本地快速滚动**：tmux 开了鼠标时，往上滚 / 手指往下滑的第一下，服务端在目标主机上执行 `tmux capture-pane` 抓出当前 pane 最近 3000 行历史（带颜色；靠打开 shell 时带上的 `LC_SSHWEB` 环境变量精确找到这个标签里的 tmux 客户端，sshd 不接受 `LC_*` 时按终端大小猜），网页盖一层历史视图，之后滚动全在本地、不用等网络（抓历史用一个常驻的通道，不用每次都在目标主机上新开通道；历史分块放进页面，最后一屏先显示，前面的在后台一块块补到上面，正在看的位置不动，打开时不卡）；看历史时输入栏自动藏起来，多出来的地方都用来显示历史（终端尺寸不变，tmux 不会重画）。历史视图里的字和实时画面一样按格子排（中文、emoji 占两格，其他一格），Claude Code 画的表格竖线对齐、占满一行的分隔线不折行。Esc、Ctrl+End / End、「回到实时画面」、滚到最底再往下（或再按 PageDown）、或直接打字都会返回（打的字照常进输入框；滚轮滚回来时这一下滚动剩下的部分不算，末尾夹着一两格反方向的抖动也不会又跳回历史视图，停一下再往上滚才重新打开）；PageUp / PageDown / Home / 方向键直接滚历史。电脑上在历史视图里拖动选中文字（双击选词、三击选行也行），松开鼠标就自动复制到剪贴板，右下角提示「已复制 N 个字符」，同终端里的选中即复制。用不了本地滚动时直接改用 tmux 自己的复制模式，这时右下角同样有「回到实时画面」（发送 q 退出复制模式，在复制模式里按 Ctrl+End 也一样；tmux 开鼠标时拖动选字也是靠复制模式实现的，那是在选字不是在看历史，不显示）；在复制模式里直接从输入框发送（或打 / 进命令模式）也行，会先自动退出复制模式再发，不会被复制模式吃掉。没有 tmux、pane 里是 vim 等全屏程序、分屏或抓到的内容和屏幕对不上时，照旧把滚轮交给程序。Claude Code 全屏模式（`/tui fullscreen`）自己接管滚轮，往上翻时出现它的「Jump to bottom (ctrl+end) ↓」/「N new messages」提示，右下角也会显示「回到实时画面」（发送 Ctrl+End 回到最新对话）；Windows 主机（SSH 默认 cmd / PowerShell，没有 sh）上的 psmux（Windows 原生的 tmux 克隆）也支持：先认出 SSH 默认的 shell（按连接记住），是 Windows 就不试 sh，找 pane（终端大小一样、最近有操作的客户端）、看模式、抓历史连成一条命令执行（Windows 开通道慢），记住 pane 和 psmux 认的 capture-pane 参数（不认 -e / -J 就去掉），切了窗口自动换 pane；Windows 的 SSH 隔着 ConPTY，备用屏幕的信号不一定传过来，所以终端开了鼠标就试；取不到时提示一次原因。Windows 主机（认出 SSH 默认的 shell 是 cmd / PowerShell）上终端开 xterm 的 windowsPty：终端隔着 ConPTY，缩放时 ConPTY 自己重排、整屏重画，浏览器里不再自己重新折行（以前两边各排各的，缩放后文字错乱，要再缩放一次才好）；Windows 主机上终端对程序询问的自动回答只发光标位置 / 状态报告：psmux 会把程序的询问（终端型号、模式、颜色）转给外面的终端，回答经 ConPTY 回去时被当成键盘输入，ESC 被吃掉、剩下的 y、c、rgb:…、\ 打进 Claude 的输入框
- **电脑输入框**：终端底部有输入框，打字在本地编辑、Enter 才整段发送，远程 / 弱网下打字不卡（文字和回车分两次写进终端，不然程序一次读到会当成粘贴、不提交：服务端等程序把文字显示出来就马上写回车，空闲时十几毫秒；最多等 50ms（正忙还没显示、输密码这类不显示的输入），同以前。发送后输入栏变矮引起的终端尺寸变化排在回车之后，Claude Code 不用先整屏重画完才处理回车）；Shift+Enter 换行（Claude Code 里按多行粘贴发送），输入框为空时 ↑ ↓ Tab ⌫ Ctrl+C 等直接发给终端，Esc 随时发给终端；tmux 快捷键（Ctrl+B 加下一个键，如 Ctrl+B D 断开、Ctrl+B C 新窗口、Ctrl+B 方向键）在输入框里也能直接用，不管输入框里有没有字；在空输入框里打 `/` 进入命令模式，之后逐字发给终端，Claude Code 的 / 命令候选列表照常弹出（↑ ↓ 选、Tab 补全、Enter 执行，Esc 或删掉 / 退出）；点终端后光标自动回到下方输入框，点击照常交给 tmux / Claude Code (tmux 开鼠标时不会误判：点击时手抖、按住后挪动不到 5px 不算拖动；连点两下 / 三下不算双击 / 三击，不会选词选行、偷偷复制覆盖剪贴板 —— 实时画面里选字用拖动，双击选词、三击选行在滚轮往上翻开的历史视图里用)；拖动选中文字时、或者终端的输入框里打过字、还没删光也没发送时（锁定在终端，方便修改，点的时候会提示「连按两下 Alt 回到下方输入框」）不抢——服务器照着每个按键模拟一份输入框的内容（插入 / 退格 / Delete / 删词 / 移动光标 / 粘贴等），所以任何设备上打的字、刷新页面前打的字都算；↑ 翻历史、Tab（补全，或空的时候填入推荐文字）、→ 采用推荐文字、Ctrl+R 搜索历史后选中一条、@ 文件列表里按回车选中、Claude Code 运行中按 Esc 打断（可能把刚发的话放回输入框）之后不知道内容，当作有字，直到回车 / Ctrl+C / Ctrl+L / Ctrl+U；连按两下 Alt 在下方输入框和终端之间切换，进终端后可直接在终端打字；只切换光标，两边的字都不动；光标在终端里时终端描一圈绿边（Claude Code 把终端光标藏起来了，不然看不出光标在哪）。顶部「✏️ 输入框」开关。输入框右边的「底部 / 浮动」按钮切换模式：浮动 = 输入框盖在终端上，拖输入框左边的把手上下调整位置；拖输入框上边缘调整高度（最低 / 默认一行，右边按钮跟着一样高、最高 60px，双击恢复当前标签的默认）；每个标签各自记住自己的模式、浮动位置和高度（新开的标签用最近一次选的 / 拖到的），每台电脑各自记住。主机状态由服务端判断（网页关着也在判断，多台设备看到的一样），变成完成 / 待选择 / 报错时推送通知（任何一台设备的网页开在前台时都不推送，最小化、切到别的窗口、或者 5 分钟没动鼠标键盘（人离开了）才推送）；右上角「🖥️ 状态」悬浮窗里每个标签一个小卡片（运行中 = 黄色闪烁，完成 = 绿色（运行停下来就算，不用等 Claude Code 的提示音；往这个标签发送内容后回到空闲），待选择 / 报错 = 红色，空闲 = 灰色；点一下切过去）
- **图片 / 文件发给 Claude**：电脑上点下方输入框 ↵ 左边的 📎 选文件（同手机），或把文件拖到终端或下方输入框上，或者在输入框 / 终端里粘贴截图（剪贴板里只有图片 / 文件时；有文字照常粘贴文字），手机上点输入栏的 📎 从相册 / 文件里选：自动传到目标主机的 `~/.cache/ssh-web/uploads`（文件名前加上时间，7 天前的自动删掉），路径填进输入框光标处、不发送，接着写要 Claude 做什么再发（下方输入框关着或在终端里直接打字时，路径直接打进终端）；别的设备在用这个标签时不上传
- **终端里搜索**：电脑上按 Ctrl+Shift+F（终端里的 Ctrl+F 留给程序：bash 光标右移、vim 翻页），或点「⋯ 更多 → 🔍 搜索历史」（手机也能用），终端区域顶部弹出搜索框：普通终端搜终端里保存的全部滚动记录（不分大小写，中文按两格选中，折行的接起来找）；tmux 里终端只有当前一屏，会先像往上滚一样打开历史视图（抓 3000 行），在历史视图里搜。打字时不搜（输入法组字不会被打断），按回车或点「搜索」才搜；找到的标出来并滚到中间（历史视图里搜索框有焦点时用高亮，焦点留在搜索框），显示「第几个 / 共几个」，搜过之后回车 = 上一个（往旧的找），Shift+回车 = 下一个，循环，改了搜索词再按回车重新搜；没找到标红；Esc 关掉搜索框（历史视图还在，再按 Esc 回到实时画面）
- **端口预览**：Claude Code 在目标主机上跑起来的开发服务（如 `localhost:5173`）这类只有本机能访问的网页，点顶栏最右边「⋯ 更多」里的「🌐 端口预览」，列出目标主机上在监听的端口（`ss` / `netstat`），点「打开」在浏览器新标签页里打开（借这个标签的 SSH 连接转发，同 `ssh -L`；页面、跳转、POST、WebSocket 热更新都能用）。地址是 `/p/<端口>-<口令>/`，口令用 `SECRET` 算出来，每个端口固定、服务重启后不变，地址本身就是凭证。默认隔离：预览页面放在浏览器沙箱里，拿不到 SSH-WEB 的登录状态、碰不到你的主机，代价是它自己的 localStorage / cookie 用不了；应用因此报错时可以给这个端口勾「完整模式」（不隔离，预览页面能以你的身份操作 SSH-WEB，只对信得过的项目打开；开发服务设的 Cookie 限定在预览地址下），每台设备按端口记住。资源用绝对路径的开发服务要设置前缀（如 Vite `npx vite --base /p/5173-xxxx/`，前缀显示在面板里）
- **SFTP 文件管理**：浏览、上传（拖拽 / 多文件 / 进度条）、下载、文件夹打包下载、新建、重命名、删除、终端 cd 到当前目录；多请求并发传输，隧道 / 外网上也能跑满带宽。点文件名或 👁 直接预览（双击照旧下载）：图片直接显示，文本 / 代码等宽显示，Markdown 排好版（标题、列表、表格、代码块等），PDF 在浏览器新标签页打开；二进制文件、超过 2MB 的文本提示下载后查看。文件里的脚本（html、svg、Markdown 里夹的 `<script>`）一律不会执行；连的是 Windows 的 SSH（OpenSSH）时，路径框显示 `D:/目录`（不显示 SFTP 给的盘符前面的 /），手动输入 `D:/目录` 也认得，「终端 cd」先认出终端里是哪种 shell（`echo %OS%;$env:OS` 一句话分辨 cmd / PowerShell / sh，按连接记住；在 psmux 里以它当前 pane 跑的程序为准），cmd 发 `cd /d "D:\目录"`（换盘符也切得过去），PowerShell 发 `cd 'D:\目录'`，发给 Claude 的附件路径也是 `C:/Users/…`
- **手机 / 弱网优化**：终端输出压缩传输；断线重连只补发缺少的输出，不重画整屏；终端用 GPU (WebGL) 渲染，Claude Code、top 等频繁刷新的程序更流畅省电（不支持时自动退回普通渲染）；iPhone 添加到主屏幕以 App 方式运行时：状态栏纯黑底白字（apple-mobile-web-app-status-bar-style=black，没有磨砂，页面从状态栏下面开始；不用 viewport-fit=cover / black-translucent，那样状态栏盖在页面上，iOS 加磨砂挡住主机标签；这个设置 iOS 在添加到主屏幕时记下，改了要删掉图标重新添加），标签栏吸顶（sticky）：iOS 26 起主屏幕网页 App 顶部有一层系统画的 Liquid Glass 边缘模糊，会盖住页面最上面的标签，网页没有开关，只有顶部是 fixed / sticky、不透明、高过约 10px、宽占 90% 以上的元素时 WebKit 才不画；有底部小横条的机型输入栏底部让出 34px（输入框和 ↵ 不被圆角挡住、不误触小横条），键盘弹出时不再留空
- **支持连接通过 Cloudflare Tunnel 暴露 SSH 的 NAS**（相当于内置了 `cloudflared access ssh`，支持 Access Service Token）
- 主机列表（分组、搜索），凭据用 AES-256-GCM 加密保存在服务器，浏览器拿不到
- 网页登录保护、登录失败限流、签名 Cookie；每台设备各自登录，用着自动续期，默认 30 天没用过才要重新登录
- 可限制允许连接的目标主机（`ALLOWED_HOSTS`）
- WebSocket 心跳，适配 Cloudflare / 反向代理的空闲超时
- 前端依赖全部本地提供，内网离线可用

## 部署（NAS Docker）

把整个目录上传到 NAS，例如 `/volume1/docker/ssh-web`，然后：

```bash
cd /volume1/docker/ssh-web
# 先修改 docker-compose.yml 里的 AUTH_PASSWORD
docker compose up -d --build
```

访问 `http://NAS_IP:8888`。

> 群晖 / 威联通 / 飞牛 等可以在「Container Manager → 项目」里选择这个目录，直接用 `docker-compose.yml` 创建项目。

不用 compose 也可以：

```bash
docker build -t ssh-web .
docker run -d --name ssh-web --restart unless-stopped \
  -p 8888:8888 -v $(pwd)/data:/data \
  -e AUTH_PASSWORD=你的密码 ssh-web
```

### 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `8888` | 监听端口 |
| `HOST` | `0.0.0.0` | 监听地址（Docker 部署保持默认即可） |
| `AUTH_USER` | `admin` | 网页登录用户名 |
| `AUTH_PASSWORD` | 空 | 网页登录密码，**为空则不需要登录**（仅限可信内网） |
| `SECRET` | 自动生成 | 用于 Cookie 签名和凭据加密，自动生成的保存在 `/data/.secret`。**丢失后已保存的密码无法解密** |
| `SESSION_HOURS` | `720` | 登录有效期（小时）：多久没用过就要重新登录，默认 30 天；打开页面、页面开着时会自动续期（以前默认 24 小时、从登录起算不续期） |
| `COOKIE_SECURE` | `false` | 通过 HTTPS 访问时设为 `true` |
| `ALLOWED_HOSTS` | 空（不限） | 允许连接的主机，逗号分隔，`*` 只匹配一段（不跨 `.`），如 `192.168.1.*,*.example.com`；Cloudflare 隧道按隧道主机名校验 |
| `TRUST_PROXY` | `loopback, linklocal, uniquelocal` | 信任哪些地址发来的 `X-Forwarded-For`（用于登录限流取真实 IP）。默认只信任内网地址（反向代理、cloudflared 容器），防止公网伪造 |
| `SSH_READY_TIMEOUT` | `20000` | SSH 连接超时（毫秒） |
| `SSH_KEEPALIVE` | `15000` | SSH keepalive 间隔（毫秒） |
| `PUID` / `PGID` | 不设置 | 设置后用这个用户（不是 root）运行，启动时自动把 `/data` 交给它；不设置时和以前一样以 root 运行 |
| `BG_TIMEOUT_HOURS` | `168` | 后台会话无人查看超过多少小时自动断开（默认 7 天；每个会话约占 3MB 内存），`0` 为永不（已断开的会话 24 小时后清理）。只断开 SSH-WEB 的这条连接，tmux 里的程序不受影响 |
| `MAX_SESSIONS` | `30` | 最多同时保留的后台会话数 |
| `SCROLLBACK` | `5000` | 滚动记录行数：后台会话保留多少行用于恢复画面，浏览器终端也保留同样的行数 |
| `PUSH_SUBJECT` | `mailto:ssh-web@example.com` | Web Push 联系方式（推送服务要求，一般不用改） |
| `HISTORY_MAX` | `1000` | 历史命令最多保存条数 |
| `HOSTKEY_POLICY` | `ask` | 主机指纹校验：`ask` 新主机和指纹变化都要确认；`accept-new` 新主机自动信任、变化时确认；`off` 不校验 |

数据都在 `./data`：`hosts.json`（主机列表，密码加密）、`known_hosts.json`（已信任的主机指纹）、`history.json`（历史命令）、`favorites.json`（收藏）、`vapid.json` / `push.json`（通知密钥与订阅）和 `.secret`，备份这个目录即可。

## 手机使用

手机 / 平板（触屏设备）连接后，底部会出现输入栏和特殊键：

- 点终端或输入栏弹出键盘（点终端上的按钮，如「回到实时画面」、「重新连接」，不弹），打字先在输入栏里编辑（不卡，文字满一行自动换行、输入栏变高），点 `↵` 或输入法的「发送」才整段发出并回车；输入栏为空时点「发送」只发回车
- 输入栏是可编辑区域（contenteditable），不是表单输入框：手机浏览器和系统的密码管理会在每个表单输入框弹键盘时，在输入法上方加一条「密码填充」栏（`autocomplete="off"` 也挡不住），换成可编辑区域就不会有。另外页面里只要有密码框，点任何输入框都可能弹这条栏：所以登录框、主机对话框里的密码框平时是普通文本框，打开时才变成密码框，关掉后变回来、填过的密码清掉；SSH 验证码对话框答完也清掉。iPhone 键盘上方那条「上下箭头 + 对勾」是 iOS 自己给所有网页输入框加的，网页去不掉
- 键盘弹出时界面缩到键盘上方；只有光标在输入框里才算键盘弹出（刚打开页面时地址栏伸缩，可视区域会短暂变矮，不会被当成键盘弹出把界面停在矮的高度）
- 输入栏为空时：退格删除终端里的字符，`↑` `↓` `Tab` 等特殊键直接发给终端；有文字时 `⌫` `←` `→` `Home` `End` 编辑输入栏，`Tab` 等其他键先把文字发出去再发按键，`Esc` `^C` 不影响正在编辑的文字
- 在空输入栏里打 `/` 进入命令模式（输入栏绿色高亮），之后逐字发给终端，Claude Code 的 / 命令候选列表照常弹出；`↵` 执行，`Esc` 或删掉 `/` 退出
- 特殊键：`历史` `Esc` `Tab` `Shift` `Ctrl` `Alt` 方向键 `Home` `End` `PgUp` `PgDn` `| / - ~` `^C` `^D` `^Z` `^L` 和粘贴
- `Shift` / `Ctrl` / `Alt` 点一下高亮，作用于下一个按键或字符，可以组合：例如 `Ctrl` + `c`、`Shift` + `Tab`（Claude Code 切换模式）、`Shift` + `↑`
- 粘贴：通过 HTTPS 访问时直接读取剪贴板，HTTP 下浏览器不允许读取，会弹出输入框让你粘贴
- `📎`（输入栏 ↵ 左边）：从相册 / 文件里选图片或文件发给 Claude，传到目标主机后路径填进输入栏

- **复制终端内容**：长按终端约 0.5 秒，或点按键栏的「复制」，弹出可选择的文本（当前画面 + 最近 1000 行；在 tmux 历史视图里长按时是整段 tmux 历史）；长按打开时，按住的那一行在面板里就在手指底下；
  可「复制全部」，或长按选择一部分后「复制选中」。局域网 HTTP 访问也能复制。在 tmux 里只能取到当前画面，先滑到要复制的位置再打开
- **字体大小**：在终端上双指张开 / 捏合调整字体（8–28），也可以用侧边栏底部「字体大小」的 `A-` `A+`；每台设备单独记住
- **自定义按键栏**：点按键栏最右边的 ⚙，可以调整顺序、删除按键，添加 `^B`（tmux 前缀）、`Esc Esc`（Claude Code 撤回）、
  F1–F12、`^R` `^A` `^E` 等和常用符号，也可以自定义按键（如名称「压缩」、内容 `/compact\r`，`\r` 表示回车、`\e` 表示 Esc、`\x02` 表示任意字节）。
  默认是原来的按键和顺序，「恢复默认」可一键还原；设置保存在服务器，多台设备共享
- **滑动查看历史**：普通界面直接滑动；Claude Code、vim 等支持鼠标的程序会收到滚轮事件自己滚动
- **tmux**：tmux 默认没开鼠标，滑动时会弹出提示，点「开启 tmux 鼠标滚动」即可（在目标主机执行 `tmux set -g mouse on`，不会往终端里打字）。
  tmux 重启后需要重新开启；想永久生效，在目标主机的 `~/.tmux.conf` 加一行 `set -g mouse on`

> 手机浏览器直接在 xterm.js 里打字会丢字、重复或不弹键盘，所以触屏设备改用这个输入栏。电脑端不受影响。

## 后台会话

SSH 连接由服务器保持，浏览器只是「挂载」上去查看和操作：

- **关闭浏览器 / 刷新 / 断网**：SSH 继续在服务器上运行（正在跑的命令不会中断），再打开网页时自动恢复所有标签、顺序和上次所在的标签，画面与滚动记录原样还原（vim、top 等全屏程序也可以）
- **多设备**：手机和电脑可以同时打开同一个会话，输入输出实时同步；一台设备新开的标签、调整的顺序会实时出现在其他设备上（不会打断正在看的标签）；验证码在一台设备上回答后，其他设备的弹窗自动关闭
- **打开页面时**：当前标签马上显示；其他标签先只同步状态（连接、主机状态、提示音提醒照常），切过去时才加载画面，标签多时打开更快、更省流量
- **关闭标签（×）** 才会真正断开 SSH，并在所有设备上同步关闭；这个标签正在别的设备上用（锁住）时会先确认；手机锁屏期间被别的设备关掉的标签，回来时直接关掉
- **SSH 自己断开**（主机重启、超时等）：保留记录，点「重新连接」用同样的参数重连，历史输出还在
- 网络中断时浏览器会自动重新挂载，不需要手动操作；只补发断开期间的输出（服务器为每个会话保留最近 1MB），画面不闪、流量很小，断开太久才重新发送整屏

> 后台会话保存在 SSH-WEB 进程的内存里，**重启容器会断开所有会话**（标签以服务端为准：服务端已经没有的标签会自动关掉，不会和别的设备新开的叠在一起；已保存的主机在侧边栏点一下就能重新连接）。
> 没有保存到主机列表的连接，重新连接需要的密码只保存在内存中。

## 性能监控

连接后点顶栏最右边「⋯ 更多」里的「📊 性能监控」，终端左侧展开面板（手机上全屏显示），每 2 秒刷新：

- 主机名、系统版本、内核、运行时间、负载
- CPU 使用率（用户 / 系统 / IO 等待）、核心数、温度（有传感器时）
- 内存、缓存、交换分区用量；超过 75% 变黄、90% 变红
- 网络上传 / 下载速度与最近 2 分钟曲线（鼠标悬停看数值），可切换网卡
- 磁盘读写速度、各分区用量
- 进程排行 Top 15，可按 CPU 或内存排序

实现方式：复用当前终端的 SSH 连接执行一段只读脚本（读取 `/proc`、`df`），不需要在目标主机安装任何东西，
兼容群晖等 BusyBox 系统；每次约 6KB 流量。只有当前标签且面板打开时才采集，切换标签或关闭面板即停止。
仅支持 Linux 主机，路由器等不支持的设备会显示提示。

## 完成通知

终端里出现提示音（BEL）或通知序列（OSC 9 / OSC 777）时，推送到开启了通知的手机 / 电脑。
由服务器发送，**手机锁屏、切到其他 App、关掉浏览器也能收到**；点通知直接打开对应标签。
网页开在前台（没最小化、浏览器是当前窗口或焦点在「📌 置顶到桌面」的小窗口上、5 分钟内动过鼠标键盘）时哪个标签都不推送，最小化、切到别的窗口 / 软件、或人离开 5 分钟才推送；侧边栏「完成通知」里列出所有开了通知的设备（浏览器 + 系统），可以单独删掉（这台没开、别的设备开着时按钮上会写「其他 N 台已开」）；同一个会话 10 秒内最多推送一次；页面上响铃的后台标签会显示 🔔。

开启：侧边栏底部「完成通知」点「未开启」→ 允许通知 → 会收到一条测试通知。

- **需要 HTTPS 访问**（如 Cloudflare 隧道的域名），局域网 `http://` 地址无法使用（浏览器限制）
- **iPhone / iPad**：先在 Safari 点「分享 → 添加到主屏幕」，从主屏幕图标打开后再开启（iOS 16.4+）
- **Claude Code**：在 Claude Code 里输入 `/config`，把通知方式设为终端提示音（terminal bell），任务完成或需要你确认时就会推送。
  在 tmux 里提示音默认会传出来；OSC 9 通知序列需要 tmux 开启 `allow-passthrough`，所以建议用提示音
- **普通长命令**：在命令后面加 `; printf '\a'`，例如 `docker compose pull; printf '\a'`

## 历史命令

点标签栏的「🕘 历史」（手机上也可以点输入栏上方的「历史」键）打开：

- **执行**（或点命令本身）：直接运行；**填入**：只填到终端里，可以修改后再回车；**✕**：删除这一条
- 默认只显示当前主机的记录，勾选「全部主机」查看所有；支持搜索；「清空」清除当前主机或全部记录
- 记录保存在服务器 `data/history.json`，手机和电脑共享，同一主机的相同命令只保留一条并显示执行次数

记录方式：按回车时读取终端上显示的这一行命令（去掉提示符），所以 Tab 补全、↑ 调出的命令都能正确记录。以下情况**不会**记录：

- 以空格开头的命令（与 bash 的 `HISTCONTROL=ignorespace` 相同，适合含密码的命令）
- 密码输入（sudo、`read -s` 等）以及 vim / top 等全屏程序里的输入
- 提示符不是以 `$` `#` `%` `>` `❯` 加空格结尾的 shell
- 网络延迟很大时，在上一条命令的回显出现之前就盲打并回车的下一条命令

> 历史命令以明文保存，命令里如果带了密码，请在前面加一个空格，或执行后在历史里删除。

## 二次验证 (TOTP)

适用于服务器开启了 Google Authenticator 等二次验证（如群晖 SSH 两步验证、`libpam-google-authenticator`）。
连接时服务器询问的「Password」会自动用保存的密码填写，「Verification code」等其他问题会在网页上弹窗让你输入，
手机上会自动弹出数字键盘。等待输入期间不会超时（最长 5 分钟）。

## 主机指纹校验

- 首次连接某台主机时弹窗显示指纹，确认后保存到 `data/known_hosts.json`
- 以后指纹不变则直接连接；**指纹变化会红色警告**，默认拒绝，确认服务器重装过才选「更新指纹并连接」
- 侧边栏底部「已信任的主机指纹」可以查看和删除
- 直连按 `主机:端口` 记录，Cloudflare 隧道按隧道主机名记录

## SFTP 文件管理

连接成功后点标签栏右侧「📁 文件」打开，复用当前终端的 SSH 连接（不用再输密码 / 验证码）。

- 点文件夹进入，路径栏可直接输入路径回车跳转
- 上传：按钮选择或直接把文件拖到列表里，带进度条，重名会询问是否覆盖；覆盖时先传到同一目录下的临时文件（`.文件名.sshweb-…`），传完再换上去，中途断网 / 取消原文件不受影响，权限保持原来的
- 下载：文件直接下载；文件夹在服务器上用 `tar` 打包成 `.tar.gz` 下载
- 「终端 cd」让终端切换到当前浏览的目录
- 传输走 HTTP 流，不占用终端的 WebSocket，大文件也没问题（通过 Cloudflare 隧道访问 SSH-WEB 时，上传单个文件受 Cloudflare 100MB 请求体限制）

> 需要目标主机开启 SFTP 子系统。群晖需要在「控制面板 → 文件服务 → FTP → SFTP」里启用 SFTP 服务。

## 连接通过 Cloudflare 隧道暴露 SSH 的 NAS

适用于这种情况：NAS 上运行了 `cloudflared`，并在 Cloudflare Zero Trust 里配置了
Public Hostname `ssh.example.com → ssh://localhost:22`。平时需要用
`cloudflared access ssh --hostname ssh.example.com` 才能连上。

在 SSH-WEB 中：

1. 新建连接 → 选择 **Cloudflare 隧道**
2. 「隧道主机名」填 `ssh.example.com`（不用填端口）
3. 填 NAS 的 SSH 用户名和密码 / 私钥
4. 如果该主机名配置了 **Cloudflare Access** 应用（大多数都会配），还需要 Service Token：
   - Zero Trust → Access → Service Auth → Service Tokens → 创建，得到 `Client ID` 和 `Client Secret`
   - 在该主机名对应的 Access 应用里添加一条策略：Action 选 **Service Auth**，Include 选 **Service Token** → 选刚创建的 token
   - 把 Client ID / Secret 填到连接表单里（Secret 会加密保存）

> 通过浏览器弹出 Cloudflare 登录页的那种身份认证（邮箱验证码 / GitHub 登录等）没法在服务端自动完成，所以必须用 Service Token，或者对该主机名不启用 Access（仅靠 SSH 密码/密钥保护，不推荐）。

常见错误：

| 提示 | 原因 |
|---|---|
| HTTP 302 / 401 / 403 | 主机名受 Access 保护，Service Token 未填、填错或策略里没放行 Service Auth |
| HTTP 502 / 530 | 隧道离线、NAS 上 cloudflared 没运行，或 ingress 没指向 `ssh://localhost:22` |
| 认证失败 | 隧道已通，SSH 用户名 / 密码 / 密钥错误 |

## 通过 Cloudflare 隧道把 SSH-WEB 发布到公网（可选）

`docker-compose.yml` 里有注释掉的 `cloudflared` 服务：

1. Zero Trust → Networks → Tunnels 创建隧道，复制 token 填到 `TUNNEL_TOKEN`
2. Public Hostname：`web.example.com → http://ssh-web:8888`（WebSocket 默认支持，不用额外设置）
3. 设置 `COOKIE_SECURE=true`
4. **强烈建议**给 `web.example.com` 加一个 Cloudflare Access 应用（邮箱验证码等），再加上 SSH-WEB 自带的登录，形成两道防线

用群晖 / Nginx Proxy Manager 等做反向代理时，记得开启 WebSocket 支持。

## 安全提示

- 这是一个「能登录你所有服务器」的入口，公网暴露时务必设置强 `AUTH_PASSWORD`，最好再套 Cloudflare Access
- 首次连接时认真核对指纹（`ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub`），不要关闭指纹校验
- 用 `ALLOWED_HOSTS` 限制可连接范围，防止被当作跳板

## 本地开发

```bash
npm install
AUTH_PASSWORD=test npm start
```

代码结构：

```
server.js              入口：组装各部分、启动服务、定时清理后台会话
lib/
  config.js            环境变量配置
  auth.js              SECRET、主机密码加解密、登录凭证签名 / 校验 / 作废、登录限流
  store.js             data/ 下的 JSON 文件：主机、已信任指纹、历史命令、收藏、界面设置
  ssh-target.js        连接参数整理 (已保存主机读加密凭据)、ALLOWED_HOSTS 白名单、主机公钥指纹
  http.js              网页和前端资源、登录 / 退出、挂载各接口
  api-data.js          主机 / 指纹 / 历史 / 设置 / 收藏接口
  api-sessions.js      后台会话列表、标签顺序、开启 tmux 鼠标、关闭会话
  ws.js                WebSocket：握手校验、浏览器消息分发、心跳
  events.js            通知所有打开的页面 (新建会话、标签顺序)
  session/             后台会话 (SSH 连接由服务端持有，浏览器只是挂载上来)
    index.js           核心：挂载 / 画面快照 / 输出转发 / 流控 / 主机状态 / 通知
    input.js           写入按键 (输入栏发送时回车等回显、终端输入框内容同步)
    size.js            终端尺寸听正在用的设备
    ssh.js             建立 / 断开 SSH 连接 (直连 / Cloudflare 隧道、指纹校验、验证码)
    remote.js          在目标主机上测延迟、抓 tmux 历史
  sftp.js monitor.js push.js status.js cli-input.js echo-wait.js   文件管理、性能监控、推送、主机状态判断、终端输入框模拟、回显判断
public/app/            前端，按编号顺序拼成 app.js (见下)
```

前端代码按功能拆在 `public/app/*.js`（文件名带编号），服务端启动时按顺序拼成一个 `app.js`：各部分共用同一个函数作用域，所以新增的部分要按依赖顺序编号；改前端代码后重启服务生效。

- 快速连按两下 `Alt`：光标在底部输入框和终端之间来回切换（输入框隐藏时会顺便打开）
