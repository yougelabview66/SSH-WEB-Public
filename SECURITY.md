# Security Policy

SSH-WEB holds SSH credentials and opens shells on your servers, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Report privately through GitHub's
[private vulnerability reporting](https://github.com/yougelabview66/SSH-WEB/security/advisories/new)
(Security → Report a vulnerability), including steps to reproduce and the affected version
(shown at the bottom of the side bar).

You should get a reply within a few days. Fixes are released on `main`; please update to the latest version.

## Supported versions

Only the latest version on `main` receives security fixes.
